# Golden QA set

The catalog tracks the ten required image categories. Phase 2 activates two owned synthetic Create cases (product reference and text-sensitive card), generated by scripts/validate-create.ts with scoped visual rubrics. Eight other categories still await suitable fixtures and rights review; this does not imply all ten have passed. Keep private inputs/outputs outside Git.

Each approved case needs input hash/path, usage rights, prompt, protected regions/identity/text, output requirements and a human acceptance rubric. Each run records engine/model/graph fingerprints, seed/settings, cold/warm state, timing, VRAM sampling and output hashes plus human assessment.

The synthetic red sphere/cube foundation smoke test is a separate infrastructure check. It is not a substitute for the permanent golden set or a product-fidelity benchmark.
