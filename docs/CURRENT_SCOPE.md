# Current product scope

The user's latest instructions supersede broader requirements in product-brief.md and earlier phase plans.

- Windows is the sole release target. Linux-specific checks and release work are unnecessary.
- Focus on excellent image generation and image editing with the installed FLUX.2 Klein 9B, Qwen Image 2.1 and SeedVR2 routes.
- Keep Create → Edit → Finish simple: one canvas, visible selections, reviewed results, preserved originals and straightforward image export.
- Prioritise prompt/reference fidelity, accurate object selection, faithful local edits, clean cutouts, upscale/restoration and reliable saving/reopening.
- Vectorisation, vector delivery, expanded branding tools, Affinity-specific handoff and additional product destinations are outside further development scope.
- Do not expand Library into a separate project. Keep only the retrieval and recovery needed for saved image work.
- Existing extras need not be removed destructively, but do not invest in extending them. Hide or simplify controls when useful to the main image workflow.
- Judge completion by representative Windows image tasks and visible quality, not feature count. Record model limitations honestly.

Continue without routine approval requests within this scope. Platform permissions and original-preservation requirements still apply.
